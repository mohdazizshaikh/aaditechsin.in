# V10.5 private owner intelligence dashboard

Source only. No new schema migration; require schema through V10.3A/V10.4. Set intelligence_dashboard.enabled=true only after isolated staging authorization, alongside portal.enabled and growth.enabled. All new flags OFF by default. Sign in through /portal/ using the existing owner login and configured TOTP. The owner sees a link to /portal/intelligence.php; direct GET requires HTTPS, admin role, matching password/TOTP fingerprint and 30-minute session inactivity limit. Guest, partner, expired/rotated session, disabled flag, invalid query and POST requests fail closed. Private no-store/noindex, frame and CSP headers from opsHeaders; no external assets/scripts, no state-changing actions. Existing session activity timestamp is refreshed on valid access. No credentials, contact fields, task drafts, organization names, source URLs, message bodies, raw provider responses or token values selected for display.

## Reporting semantics

7 and 30 completed UTC days (start inclusive, today exclusive) for saved inquiry cohort and imported communications only. Inquiry status is current status of records created in window, not transition events, revenue, or confirmed sales. Converted means case created. Opportunity pipeline is all-time current statuses by known service, not verified demand. Review queue shows oldest 20 pending/regeneration tasks with ID/revision/service/type only. Due reviews show first 20 open due/overdue qualified opportunity reminders, UTC dates. Use existing owner Telegram commands for actual review/approval. Communications show counts on reported days only and coverage (days reported / window), daily detail, missing vs true zero. Gmail latest sanitized metadata snapshot retains expiry, generation and stale rules; unread is not unanswered. Publication counts span all 12 ledgers and are historical/current status evidence, not reach, impressions or provider visibility. OAuth local policy/identity evidence is not permission to publish. Disabled modules explicitly indicated; no fabricated values. No automatic alerts beyond existing owner report schedule.
