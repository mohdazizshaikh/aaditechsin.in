## Native provider reporting

Set communications.native_usage_enabled and explicit source enabled/authorized only after owner permission, privacy review and real provider acceptance. Each source needs a private non-secret random 32-hex generation label, local expires_utc deadline and revoked=false; rotate generation on account/credential changes. Local deadline is not provider introspection; <=10 minutes blocks. WhatsApp requires exact WABA numeric account ID, supported Graph API version and authorized token with whatsapp_business_management permission. Twilio sources twilio-sms and twilio-calls require exact AC account SID, restricted SK API key with usage-read permission and secret; independently verify least privilege. Do not use master auth token. Private CLI php secure/maintenance/native-usage.php --check SOURCE (local only) or --capture SOURCE (explicit read). Pause blocks capture before request and before commit.

WhatsApp GET fixed graph.facebook.com account analytics for previous completed UTC day; accepts exact account, DAY granularity and exactly one matching start/end data point, sent and delivered counts. No response pagination; empty results or provider timezone mismatches fail closed. Requests only analytics fields; actual nested field projection and UTC bucket alignment must be verified with provider. Twilio GET fixed api.twilio.com Daily Usage Records for sms-inbound or calls-inbound, exact day, account, count unit and single row without next page. Count is provider-reported usage, not necessarily unique conversations, answered calls or missed calls; inbound calls category does not include every telephony product. Missing data is not zero. Provider reporting may lag or be revised; one latest snapshot per source may be refreshed, not an immutable daily aggregate. Do not infer response rates or combine these figures with manual/bridge received/answered/missed counts.

Only count(s), source, day, captured time, generation and account SHA256 stored in growth_native_usage. Account hash is a binding, not anonymity guarantee. No message IDs/bodies, phone numbers, call details, recording, raw provider response or credentials stored/logged. /nativeusage, /intelligence, daily owner report and private dashboard show previous completed UTC day only, matching current generation/account and expiry, labeled provisional. Existing CSV does not export native metrics. No inbound webhook, response handling, direct sending, automatic scheduler or actual consent. Snapshot retention beyond latest-per-source replacement remains subject to approved policy.
