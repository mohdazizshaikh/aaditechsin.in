## Authorized Search Console collection

Set seo.enabled, growth.enabled, seo.search_console.enabled and authorized only after owner-approved staging and actual Google consent. Dedicated OAuth application with exact https://www.googleapis.com/auth/webmasters.readonly scope and privately stored authorized refresh_token, client_id, client_secret. Never share Gmail or GBP credentials. Configure one exact Aaditechs Search Console property from sc-domain:aaditechsin.in, https://aaditechsin.in/, https://www.aaditechsin.in/ (these are allowlisted, not confirmed verified properties). Configure a fresh random 32-hex generation, revoked=false and review_expires_utc YYYY-MM-DDTHH:MM:SSZ. The deadline is an operator review gate, not provider refresh-token expiry. <=10 minutes blocks. Rotate generation on account/property/credential changes. Do not expose refresh credentials in Git or logs.

Private CLI php secure/maintenance/search-console.php --check validates local config without network. Explicit --capture requires active growth before any network request and again before snapshot commit. Exchange one refresh grant at fixed Google OAuth endpoint; require Bearer, exact read-only scope in response, bounded token lifetime, no unexpected refresh_token field. Missing scope or rotation fails closed, even if valid provider responses omit scope. Access token is used only in memory, not saved in active configuration, DB or logs. Exact property and permission verified with Sites GET, then Search Analytics query at fixed Google host. Although query uses POST, the API operation is read-only and does not request indexing or alter settings. No scheduler, consent UI, other provider renewal or automatic Gmail activation. No provider response printed.

## Metric definitions

Query finalized web search data (type web, dataState final, aggregationType byProperty), grouped only by date. Seven inclusive Pacific Time dates ending three calendar days before current Pacific date, not IST or UTC. Three-day lag is a conservative chosen window, not a guarantee of final data availability. Validate at most seven distinct dates, exact date range, integer-valued counts and finite position. Store returned-day count, total clicks/impressions and impression-weighted average position (rounded four decimals, absent if no impressions); no search terms, pages, individual visitor or raw response. Missing dates are unknown coverage, not zeros. A returned day with zero impressions is different from an absent day. Empty response with matching aggregation reports no recorded data, not zero traffic; provider responses with unexpected aggregation fail closed. Counts are Search Console search metrics, not unique site visits, leads or measured keyword rankings. No query-level or page-level analytics, CTR forecasting or competitor claims. Latest snapshot only; stale beyond 24 hours or mismatched generation/property/window hidden. No historical trend storage or CSV inclusion. /searchconsole, /intelligence, daily owner report and private dashboard display sanitized aggregate; /seo remains the source-audit command. Daily owner notification still requires existing opt-in.

Official API references: https://developers.google.com/webmaster-tools/v1/searchanalytics/query and https://developers.google.com/webmaster-tools/v1/how-tos/authorizing and https://developers.google.com/webmaster-tools/v1/sites/get and https://developers.google.com/identity/protocols/oauth2/web-server .
