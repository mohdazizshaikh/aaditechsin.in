# V10.7A — Private competitor editorial evidence comparison

Source-only continuation of V10.6Z. Prior incremental #66 and cumulative #67 CI passed (45611270486, 45611277772). No migrations, HTTP requests, provider credentials, publishing or deployment.

## Scope and operation
An authorized operator may manually review permitted public pages and prepare a private JSON file; no automated collection or copying. Use `python3 workers/competitor-evidence.py --compare-reviewed < /PRIVATE/evidence.json > /PRIVATE/comparison.json`. Never commit actual evidence files to this public repository. The worker reads at most 128 KiB, rejects duplicate JSON keys, nonfinite constants, unknown fields, invalid host/URL/date, duplicate subjects or service records, and only accepts exact service registry IDs. Select own aaditechs.in and 1–5 distinct peer hostnames. Source URLs must be exact HTTPS subject host, clean path, no query, credentials, fragment, private route, port or path traversal; this is syntactic validation, not proof of public accessibility or domain ownership. Use actual observation UTC day within 30 days. The comparison never makes network requests.

Input example (synthetic only; replace with reviewed observations):

```json
{"version":1,"scope":"reviewed-public-editorial-evidence","subjects":[{"host":"aaditechs.in","observations":[{"service_id":"it-amc","source_url":"https://aaditechs.in/it-amc/","observed_on":"2026-11-25","signals":{"service_scope":"unknown","process_explained":"unknown","limitations_explained":"unknown","contact_route":"unknown","case_evidence_visible":"unknown","maintenance_options":"unknown"}}]},{"host":"peer.example","observations":[{"service_id":"it-amc","source_url":"https://peer.example/it-amc/","observed_on":"2026-11-25","signals":{"service_scope":"unknown","process_explained":"unknown","limitations_explained":"unknown","contact_route":"unknown","case_evidence_visible":"unknown","maintenance_options":"unknown"}}]}]}
```

Six editorial signals across all 14 service categories: scope, process, limitations, inquiry route, visible case evidence and maintenance options. Present/absent/unknown refer only to observed page content; absence must be explicitly observed, never inferred from missing records. Visible case material is not verified customer proof. All 84 service/signal cells remain visible even when data are missing. Output per-subject coverage, per-cell peer evidence references/dates, distinct present/absent/unknown counts, own observation, review candidate or insufficient evidence and limited action suggestions. Only explicitly absent own content with at least one observed present peer generates a candidate; owner independently verifies relevance, rights, business capability and wording before any change. No aggregate competitor rankings, keyword volume, traffic, market share, service quality, intent or automatic outreach. Digest is canonical input identity, not a signature or attestation. No database storage, scheduler, public UI or API.
