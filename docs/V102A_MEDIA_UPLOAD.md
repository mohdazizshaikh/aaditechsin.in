# V10.2A private media staging and YouTube upload foundation

YouTube only. No live uploads, authorization, public asset URL or Instagram connector. Default OFF. Official references: https://developers.google.com/youtube/data/reference/rest/v3/videos/insert and https://developers.google.com/youtube/data/guides/using_resumable_upload_protocol and https://developers.google.com/youtube/terms/required-minimum-functionality. Confirm actual OAuth scopes (youtube.upload plus channel read access), developer policy/audit and channel identity before acceptance. Unverified API projects can be limited to private visibility.

Apply additive V10.2A migration after V10.2 on backed-up staging. Create a 0700 private sibling directory outside webroot and set media_upload.private_root. Transfer approved local MP4 manually over authenticated SFTP into a private location, never public_html. Limit 20 MiB. CLI reads exact bytes and validates SHA256 against approved current YouTube manifest plus MP4 ftyp signature (not full decoding or malware validation). Trusted local generated files only, review actual video and metadata. Storage is content-addressed, 0600; no public asset endpoints, no retention cleanup yet. Failed DB commits can leave an orphan file; reconcile manually. Configure private media_upload.youtube with exact UC channel ID and authorized access token. No OAuth issuance/refresh implemented.

Commands: php secure/maintenance/upload-worker.php --check-target. Prepare explicit JSON metadata with title, description, category_id, visibility (private recommended for testing, unlisted/public require explicit choice), made_for_kids boolean, synthetic_content boolean. Run php secure/maintenance/upload-worker.php --stage TASK REV MANIFEST_SHA256 /private/path/creative.mp4 < metadata.json. The server stores approved-hash bytes and immutable metadata, pending separate review. /uploads lists rows; /upload ID displays metadata and hashes (Telegram length limit may truncate long descriptions; review full metadata locally). /approveupload ID MANIFEST_SHA256 VISIBILITY CHANNEL_ID authorizes the exact immutable upload; /cancelupload ID before sending. Execute explicit php secure/maintenance/upload-worker.php --run ID only after owner approval; no cron. Worker rechecks revision, manifest, bytes, pause and OAuth channel before creating one resumable session and sending one PUT. Provider session URL must be exact Google HTTPS host/path. Never retry uncertain sends; reconcile manually in YouTube Studio. Provider receipt validates ID, channel and visibility; processing and public visibility independently verified. Pause blocks claims, not in-flight calls. No notifications to subscribers requested.

No automatic cross-post or production deployment.
