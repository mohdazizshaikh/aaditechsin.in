## Remote feed admission and cadence

Existing private discovery-feed.php --dry-run validates configured authorized sources without network or DB access. --run explicitly attempts sources; existing fixed HTTPS/public IPv4 pinning, bounded JSON, no redirect/proxy controls remain. Feed envelope now requires exactly version and items fields. Admission obtains the existing growth-control transaction lock, refuses paused growth or an unresolved running row for the same source, and records a run with UTC started_at. Optional discovery.cadence_enabled and minimum_interval_minutes (integer 60–10080, example 1440) gate attempts by previous started_at for the source across statuses. Local batch runs with the same source ID may also delay remote reads. Not-due skips without network or new run; no cron installed. Cadence limits attempts, not successful results, and does not guarantee a schedule. Pause checked again after fetch and before each imported record under the growth lock; no subsequent records imported while paused. Already committed partial records remain; they require owner review. Running row must still exist before each import, so a reviewed interrupted row cannot continue inserting after resume. In-flight network requests cannot be cancelled by pause. Local batch savepoint makes imports and successful run ledger atomic even if caller catches exception. No auto-qualification or outbound outreach.

## Interrupted run recovery

Private CLI php secure/maintenance/discovery-recovery.php --inspect RUN_ID provides source/run/started timestamp and SHA256 of exact stored run state, only for running rows at least one hour old. Age is not proof process stopped. Verify processes and imported opportunity evidence independently. Only when confirmed stopped, run --confirm-stopped RUN_ID STATE_SHA256 to mark exact unchanged run failed with operator_interrupted and sanitized audit. No opportunity deletion, evidence edit, automatic replay, or reclassification of prior imports. Interrupted counters may be incomplete because the ledger updates on finish; review actual imported evidence. Recovery does not prove remote source state. Existing release gate blocks remaining running rows. No actual recovery performed.
