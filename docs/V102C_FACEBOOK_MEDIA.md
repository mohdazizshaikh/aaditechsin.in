Apply V10.2C after V10.2B. Independently enable media_upload.facebook_enabled plus existing media/social/meta/Facebook flags only on approved test environment. Local-media verify now checks hashes, Pillow PNG integrity/profile, ffprobe H.264 dimensions/duration and decodes video using local FFmpeg. This is local validation of trusted generated assets, not a server-side full decode or platform certification. Server checks exact SHA256 and PNG header dimensions or basic MP4 signature. No public URL. Exact bytes passed to CURLStringFile. PHP 8.1+ with cURL required; confirm host memory and limits.

Private CLI: php secure/maintenance/facebook-media-worker.php --check-target verifies Page identity; --stage TASK REV MANIFEST_SHA256 photo|video /private/path/asset stages the approved manifest and caption. /fbmedia and /fbasset ID review; /approvefbmedia ID SHA256 photo|video PAGE_ID explicitly authorizes public post. /cancelfbmedia ID cancels unsent only. --run ID performs one explicitly authorized send after exact revision/manifest/target/pause/hash checks. No scheduled media cron. Photo and video mutually exclusive with Facebook text for same revision (even cancelled rows reserve revision). No automatic retries; sending/unknown require manual reconciliation. API receipt is resource ID, not proven processing or visibility. No posts sent by tests.
